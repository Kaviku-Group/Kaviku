# Игры Kaviku

**Добавить игру = скопировать готовую папку игры сюда и опубликовать сайт.**
Регистрировать игру, править код или запускать проверки при добавлении не нужно.

```
games/
├── README.md                ← эта инструкция
├── _template/               ← шаблон (папки с «_» на сайт не попадают)
└── neon-courier/            ← папка игры; из её имени получается адрес /games/neon-courier
    ├── index.md             ← данные игры + полное описание
    ├── cover.jpg            ← обложка
    └── screenshots/         ← скриншоты (необязательно)
        ├── 01.jpg
        └── 02.jpg
```

## Добавление (каждый раз)

1. Скопировать готовую папку игры в `D:\Kaviku\games`.
2. Опубликовать:
   ```
   npm run deploy
   ```

При первом запуске команда запоминает уже опубликованные папки. При последующих запусках новая папка игры автоматически получает текущую дату и время в `publishedAt` (игры с `draft: true` получат дату, когда черновик будет опубликован). Скрипт обновляет `games/.published-games.json`; сохраните этот файл вместе с новой игрой, чтобы следующие публикации распознавали её как уже опубликованную.
Игра сама появится в каталоге, в фильтрах по её жанрам и тегам и в поиске.

Скрыть игру — `draft: true` в её `index.md`. Удалить — удалить папку. После этого снова `npm run deploy`.

Если в папке всё же есть ошибка, сайт **всё равно опубликуется**, а эта игра будет пропущена.
Причина видна в выводе команды, в строке «Игра в папке … пропущена».

## Подготовка папки (заранее, один раз на игру)

1. Скопировать `_template`, переименовать. Имя может быть любым — «Neon Courier», «Неоновый курьер»,
   `neon-courier`: адрес страницы получится автоматически (`neon-courier`, `neonovyy-kurer`).
   Чтобы задать адрес вручную, добавьте в `index.md` строку `slug: my-game`.
2. Положить обложку и скриншоты (JPG, PNG, WebP). Сжимать не нужно — сайт сделает лёгкие версии сам.
3. Заполнить `index.md` (подсказки — в комментариях шаблона).
4. Проверить папку:
   ```
   npm run game:check -- "C:\путь\к\папке"
   ```
   Проверяются обязательные поля, жанры, теги, возрастная маркировка, даты, формат ссылок,
   наличие и целостность картинок; ссылки дополнительно открываются для проверки.
   «✔» — папка готова к копированию.

Сама игра (ZIP/EXE/APK) в папку **не кладётся**: она размещается на itch.io, GitHub Releases,
Google Drive и т. п., а в `downloadUrl` указывается ссылка (в Cloudflare Pages файл не может быть больше 25 МБ).

## Два языка: русский и английский

Сайт работает на двух языках: русская версия — `/games/…`, английская — `/en/games/…`
(переключатель RU / EN в шапке). Английские тексты игры задаются в том же `index.md`:

**1. Название и краткое описание** — блок `en:` между линиями `---`:

```yaml
title: Неоновый курьер
shortDescription: Доставляйте посылки по ночному городу.
en:
  title: Neon Courier
  shortDescription: Deliver parcels across the night city.
```

**2. Полное описание** — под второй `---`, части отмечаются строками `<!-- ru -->` и `<!-- en -->`:

```markdown
<!-- ru -->
## Об игре
Русский текст…

<!-- en -->
## About the game
English text…
```

Если английской части нет — на английской версии показывается русский текст (игра не пропадает).
`npm run game:check` подскажет, чего не хватает.

**3. Жанры и теги.** Базовые (таблицы ниже) переводятся сами. Для нового жанра или тега перевод
пишется через «|»: `Киберпанк | Cyberpunk`. Без перевода на английской версии он показывается как написан.

## Плашка языков игры (RU / EN)

В левом верхнем углу обложки — языки самой игры. Задаются полем `language`:

```yaml
language: RU          # один язык
language: [RU, EN]    # несколько
```

Подходят коды `RU`, `EN`, `DE`, `ES`… и слова «Русский», «English», «РУ», «ЕН», «Немецкий»…
Как и с жанрами, **любой другой язык тоже можно** — плашка появится сама с тем написанием, что указано
(«Эсперанто» → «RU / Эсперанто»).
**Если поля нет — сайт определит языки сам:** русский текст в названии или описании → RU,
есть английская версия (блок `en:` или часть `<!-- en -->`) → EN.

### shortDescription и полное описание — это разные вещи

- `shortDescription` — **обязательное поле в блоке между `---`**. Короткий текст для карточки
  в каталоге и блока «Игра недели», 1–2 предложения, до 200 символов. Без него игра будет пропущена.
- Полное описание — текст **под второй `---`**. Оно не заменяет `shortDescription`.

```yaml
shortDescription: "StandStrike — сетевой шутер с кейсами и промо-кодами."
```

## Жанры и теги

**Можно писать любые жанры и теги** — новые автоматически появятся в фильтрах каталога.
Ничего регистрировать не нужно.

- Регистр, лишние пробелы и «ё» не важны: `Шутер`, `шутер`, ` Шутер ` — один жанр.
- В фильтрах показываются только жанры и теги, которые есть хотя бы у одной опубликованной игры.
- Если одно значение написано по-разному в разных играх, в фильтре будет самое частое написание
  (при равенстве — «С заглавной буквы»).
- Жанр и тег с одинаковым названием (например, «Шутер») — это разные фильтры.
- `npm run game:check` подскажет, какие жанры и теги будут новыми.

## Платформы (поле `os`)

```yaml
os: Windows                         # одна
os: [Windows, Linux, macOS]         # несколько
```

Показываются **синими** значками под жанрами и тегами (на карточке, в «Игре недели», на странице игры)
и в фильтре каталога «Платформы» (любая из выбранных). Клик по значку — каталог с этой платформой.
Как и с жанрами и тегами, в фильтре показываются только платформы, которые есть хотя бы у одной игры.

Базовые: Windows, Linux, macOS, Android, iOS, Браузер, Steam Deck. Написание не важно:
`Win`, `Windows 11`, `PC` → Windows; `Mac`, `OS X` → macOS; `Web`, `HTML5` → Браузер.
Как и с жанрами, **незнакомая платформа создаётся сама** (перевод — через `|`: `Консоль | Console`).

## Файл игры прямо в папке

Вместо ссылки можно положить сам файл игры в её папку:

```
games/my-game/
├── index.md          ← downloadUrl: ./my-game.zip
├── cover.jpg
└── my-game.zip       ← файл игры
```

Кнопка «Скачать игру» скачает его прямо с сайта, без сторонних сервисов (скачивание засчитывается).

- **Не больше 25 МБ** — это ограничение Cloudflare Pages на один файл. Больше — загрузите игру на
  itch.io, GitHub Releases или Google Drive и укажите ссылку `https://…`.
- Форматы: `zip 7z rar tar gz exe msi apk aab dmg pkg appimage deb rpm jar love x86_64 sb3 pck html htm`.
- **HTML-игры** (один файл `.html`) тоже можно: они всегда **скачиваются** файлом с исходным именем
  и никогда не открываются как страница сайта — так безопасно. Если у HTML-игры есть отдельные
  картинки, звуки и скрипты, упакуйте всю папку игры в `.zip`.
- Файл можно положить и во вложенную папку: `downloadUrl: ./files/my-game.zip`.
- Если файл больше 25 МБ, не найден или формат не подходит — игра будет пропущена с понятной
  причиной, а `npm run game:check` покажет её заранее.

## Видео

Поле `videoUrl` — одна ссылка или список. Видео показываются **первыми** в ленте скриншотов
со значком ▶ и открываются во встроенном плеере на весь экран.

```yaml
videoUrl: https://www.youtube.com/watch?v=XXXXXXXXXXX
```
```yaml
videoUrl:
  - https://youtu.be/XXXXXXXXXXX
  - https://vkvideo.ru/video-123456_789012
```

| Сервис | Примеры ссылок |
|---|---|
| YouTube | `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…` |
| VK Видео | `vkvideo.ru/video-123_456`, `vk.com/video-123_456`. Если видео не воспроизводится — возьмите ссылку из «Поделиться → Экспорт» (`vk.com/video_ext.php?…&hash=…`) |
| Rutube | `rutube.ru/video/…/` |
| Свой файл | прямая ссылка `https://…/trailer.mp4` или `.webm` |

Превью: у YouTube — кадр из видео, у остальных — обложка игры.
Неподдерживаемая ссылка — ошибка (игра будет пропущена), `npm run game:check` подскажет.

## Возрастная маркировка

Отдельное поле `ageRating`, не жанр и не тег. Показывается плашкой в **правом верхнем углу обложки**
(на карточке, в «Игре недели» и на странице игры); языки игры — в левом.

Как и с жанрами, подходит **любой возраст в формате «N+»** — плашка появится сама:
обычно `0+`, `6+`, `12+`, `16+`, `18+`, но можно и `10+`, `13+`, `21+`. Пишите в кавычках: `ageRating: "10+"`.
Можно и просто число — `10` станет `10+`. Не возраст (например, `"для всех"`) — ошибка с подсказкой.
Поле необязательное — если маркировки нет, удалите строку. Для 18+ и старше рамка плашки красно-оранжевая.

## Игра недели

Выбирается **автоматически**, вручную ничего делать не нужно:

- побеждает игра, набравшая **больше всех лайков за прошедшую неделю**
  (с понедельника 00:00 до понедельника 00:00 по Москве);
- новая «Игра недели» появляется **каждый понедельник в 00:00** и не меняется до следующего понедельника;
- ничья → больше лайков **за всё время** → больше **скачиваний** за всё время → более новая игра.

Рядом с заголовком блока показывается, сколько лайков игра набрала за неделю.

## Страница автора

Клик по никнейму автора (на карточке, в «Игре недели», на странице игры) открывает
`/authors/<ник>` — все игры этого автора. Отдельно ничего заполнять не нужно: игры собираются
по полю `author`, поэтому **пишите ник одинаково во всех играх автора**.

## Лайки и скачивания

Хранятся в базе Cloudflare D1 и видны всем посетителям. Лайк — один на посетителя (повторное нажатие
убирает его), скачивание засчитывается не чаще раза в сутки от одного посетителя.
