## Разработка

```bash
npm install
npm run dev
```

Основные команды:

- `npm run build` — собрать сайт
- `npm run check` — проверить типы
- `npm run game:check -- "путь"` — проверить папку игры

Материалы игр хранятся отдельно от репозитория. Инструкция и шаблон находятся в [games/README.md](games/README.md).
